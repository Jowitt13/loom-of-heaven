## Goal

一句话目标：**只讲本轮有关的内容，并让用户一眼看出重点；追问沿原点深入，不被无关条件拖回全盘。**

本轮只有一个连贯改动，包含三个相互配合的部分：

1. 修复绑定交付中「未使用事实的专属 caveat 仍被强制表达」的实际缺陷。
2. 允许受控的短标题、加粗、要点列表，打通草稿校验到最终展示，不让格式在检查后另加。
3. 精简选材与追问写法，避免全体系铺陈、行为画像扩写和重复边界说明。

不改排盘结果，不扩来源准入，不追求某家模型的口吻，也不做新的应用界面。

## 2. 范围修复的固定决策

### 2.1 原计划与绑定完全保留

- 保存并校验完整原 answerPlan，planDigest 仍覆盖完整计划。
- 原草稿内容及格式均进入 draftDigest；不得伪造、裁剪或重封旧草稿冒充当前请求。
- 不改变 requestDigest 的对象、输入修订、topic/lens/at/now、settings 和现实信息绑定。
- 不允许宿主手改 selectedFacts、allowedFactIds 或 requiredCaveats 来生成「容易过」的计划。
- 不新增 focus 字段、事实选择 CLI 动词、会话状态、注册表或模型选择器。

### 2.2 只修事实专属 caveat 的必需性

普通绑定交付内部，在有界解析、版本检查及绑定匹配之后：

1. 从本轮草稿所有段落的 `sourceFactIds` 取得实际引用集合。
2. 引用必须解析到完整计划中的事实；未知 id 仍按现有错误拒绝，不能通过先取交集抹掉。
3. 用事实自己的 `caveat` 精确映射到原计划 `requiredCaveats` 的下标。
4. 已引用事实拥有的 caveat 必须表达；同一 caveat 由多个事实共享时，只需满足原有一次表达要求。
5. 未引用事实独占的 caveat 不再强制表达。没有归属信息的原有必要 caveat 保守保留，不猜它无关。

不按中文包含「五行」等关键词特殊处理，不按 fact-3 等固定编号写特判。
这是一般的事实归属规则，不是为样例开口子。

### 2.3 保持原下标与声明一致性

原 `requiredCaveats` 数组不删、不排序、不重新编号，`constraintRefs` 始终指向原计划下标。
在现有验证逻辑内部使用可信派生的「本轮必需下标集合」判断缺失；不得让宿主通过 JSON
提供 override、skip、scope 或 requiredIndices 来决定哪些约束免检。

允许最小内部参数或私有辅助函数实现，但必须复用现有有界解析、引用校验、安全扫描和结果格式，
不是新建第三套验证器。若跨模块确需现有 interpret index 的小型导出，只能服务这项内部调用。

即使某 caveat 本轮不强制表达，只要草稿主动引用或声明表达了它，原有真实下标与 attestation
一致性检查仍要执行；不能保留无效引用或互相矛盾的声明。

### 2.4 不随本轮放宽其他限制

- 本轮不重做 warning 的选择算法；完整计划已有 `requiredWarningCodes` 仍按现有语义检查。
- `TIME_UNKNOWN`、`NEAR_BOUNDARY` 等既有必要披露不能消失，也不去重改下标。
- guardrails、disclaimers 的原有适用规则、answerability、不可答原因保持不变。
- 低层结构检查只有约束信封、没有完整事实归属时，保持「全部 requiredCaveats 必需」的原行为。
- 真正只有限制说明、没有可答事实的路径继续可用；有实质解读却没有来源不能借空引用清空义务。

本轮不承诺一次解决所有警告相关性、所有自然语言蕴含或所有追问理解问题。

## 3. 清晰排版的固定决策

### 3.1 允许灵活层级，不要求固定报告

默认表达改为「便于扫读的自然叙述」，不再规定只能连续自然段：

- 先给用户一个与当前问题有关的重点，不先复述全部输入或全盘结构。
- 内容较多时用短标题分组；标题概括本组内容，不固定套性格/事业/感情/财运全套栏目。
- 并列信息用简短列表，一个要点一件事；不把所有句子拆成碎片。
- 重点词或短句适量加粗，正文保留普通字重，不全篇加粗。
- 段落和列表之间留白；不为凑整齐增加内容。
- 短追问可以只有一两段，不强制标题、固定三个特点、固定字数或固定四体系份额。
- 限制放在相关判断旁；不自动附技术面板、声明区、证据尾段或「还想看什么」菜单。

标题不得承载正文没有依据的新结论。排版借鉴不开放截图中的职业适配、读心、关系断语或性标签。
字型、字号、背景和最终行距由 WorkBuddy 控制；Skill 只控制文本结构，不制作新 UI 或 CSS。

### 3.2 用 reading-draft/v3 显式承载有限 Markdown

采用一个明确的兼容扩展，不提供多条待选路线：

- 新增 `reading-draft/v3`，沿用现有 JSON 字段和引用结构，不引入通用富文本 AST。
- 普通新生成草稿使用 v3；旧 `reading-draft/v2` 继续支持，仍执行原纯文本限制。
- v2 原来允许的普通字符（例如行首横线）不额外收紧；「保留旧版」不是借机修订其历史字符规则。
- 已拒绝的 v1 继续拒绝，不复活 section-id 免检。
- 不改变 answer-plan/v2、answer-binding/v1、answer-delivery/v1、validation-result/v2 的记录形状。
- 不新增 CLI 开关、错误码、依赖或外部 Markdown 渲染器。

v3 支持范围只限于：

| 部位            | 允许语法                                     | 明确边界                                                         |
| --------------- | -------------------------------------------- | ---------------------------------------------------------------- |
| section.heading | 纯文本，或以 `## ` / `### ` 开头的单行短标题 | 不开放任意 HTML、链接、图片、其他复杂标记；标题也受安全扫描      |
| paragraph.text  | 普通文字与成对的 `**重点**`                  | 不嵌套、不跨行、不接受空或未闭合强调；不靠标记分割危险词绕过检查 |
| paragraph.text  | 简单 `- ` 要点行和正常段落换行               | 事实/现实/约束引用仍跟随现有段落；不用表格、代码块或复杂嵌套     |

标题和标记由宿主写入草稿；交付仍按原顺序逐字转写字段，不在成功后增加标题或加粗。
这样不需要另建渲染服务或更改已检查正文的展示承诺。

### 3.3 受控语法不是把安全扫描关掉

在现有资源限制内做确定性的轻量检查：先识别 v3 允许的有限标记，得到对应可见文字用于
原有安全规则扫描。两者边界必须清楚：

- 原始输入大小、字段数、字符数、数组数和违规输出上限全部保留；标记也计入输入预算。
- HTML、实体、链接、图片、自动链接、反引号代码、转义技巧、表格等未支持结构仍拒绝。
- 未闭合/非法组合不能「修好后放行」；返回现有受控违规，不自动替用户改文本。
- 扫描标题、列表和强调中的可见内容；`必**然**结婚` 不能因为加粗而漏检。
- 保留原有 Unicode、零宽字符和换行拆词防护；不得先删掉危险文本或扩大免责声明屏蔽范围。
- v2 不能因 v3 存在而获得 Markdown 权限；旧结构入口也不允许带格式跳过安全检查。
- `lintReading` 检查最终将展示的 body。只移除「所有标题一律禁止」这一条，保留后台泄漏、
  固定免责区、空话、重复、无依据确定性表达等原有检查及必要回归。

## 4. 内容组织与行为扩写的固定处方

### 4.1 初答选择解释价值，不选择技术数量

从已有获准含义里抓少数主线，先讲清最值得理解的一点；需要时补一个相关侧面。
这不是强制数字配额。用户明确要求全面展开时可以增深，但不能把每个体系都填满当默认完成标准。

只有 Magha/Simha/宫位等位置、没有当前可用含义时，不为展示四体系齐全而塞进正文。
强弱分类也不自动变成主见、心理能量、承受力、工作需要或职业偏好。
十神位置不自行变成「看重实际回报」等含义；没有对应获准解释，就保持结构边界。

### 4.2 追问是解释原点，不是再开一份性格报告

用户问命宫武曲破军，就解释这条材料和必要条件；不顺带补五行、其他体系或全部四化。
不重新科普已解释过的术语，不把「敢变」扩成缺耐心，不把「善执行」扩成答应必做完。

比喻只对应概念，不认定习惯：老房翻新可以用于说明「落实方案」与「改变旧做法」的区别，
不能继续安排这个人如何花钱、先拆后建、讨厌审批或会怎样对待别人。
无需为这个问题再增加一套禁词，改好现有原则与示例即可。

### 4.3 质疑不符合时，及时收窄并停止

保留真实第三轮开头的优点：不拿标签覆盖用户观察，指出例子只说明概念，具体说过头的句子收回。
不为维护结论自动增加「还要看三方四正」「再核时间」等补救路线；只有真实输入问题与当前判断
直接相关时才简要说明。承认不符之后不重讲全盘、所有限制和无关五行。
