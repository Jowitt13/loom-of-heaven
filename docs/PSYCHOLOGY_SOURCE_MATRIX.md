# Psychology and mental-health source matrix

This registry is the evidence and licensing companion to ADR 0014. It records what may be used,
what may only be studied, and what remains blocked. A project name or public PDF is not sufficient
authorization to bundle item text or claim clinical validity.

- Reviewed: 2026-08-13
- Current status: **P2 and P3 have internal, source-bound primitives only. No psychology
  questionnaire, profile, or screening capability is shipped through a user-facing Skill, CLI,
  host package, or chart result.**
- Default repository license route: MIT/BSD/Apache/ISC runtime dependencies only unless the owner
  explicitly approves another route.
- Separate all four questions for every source: software license, questionnaire-content rights,
  translation rights, and clinical-use limits.

## Status vocabulary

| Status                    | Meaning                                                                                        |
| ------------------------- | ---------------------------------------------------------------------------------------------- |
| `CANDIDATE`               | Worth source-binding and validating; not authorized to ship.                                   |
| `PLANNED`                 | Selected in ADR 0014, but all release gates still apply.                                       |
| `IMPLEMENTED_INTERNAL`    | Source-bound internal code exists; it is not a public capability or release claim.             |
| `IMPLEMENTED_UNPUBLISHED` | A bounded public source bundle exists and passes local gates; it has no host or Release claim. |
| `PROFESSIONAL_ONLY`       | May be considered only in a qualified-professional/research surface.                           |
| `BLOCKED_LICENSE`         | Rights are incompatible, unclear, or require permission not yet obtained.                      |
| `BLOCKED_TRANSLATION`     | No sufficiently verified Mandarin form is bound for the intended use.                          |
| `REFERENCE_ONLY`          | May inform architecture/testing; do not copy or bundle its content/code.                       |
| `EXCLUDED`                | Do not use, copy, derive from, or claim as evidence.                                           |

## P3 internal IPIP-NEO-120 source binding (2026-08-13)

`@loom/personality-assessment` now contains a local, deterministic IPIP-NEO-120 primitive under
`IMPLEMENTED_INTERNAL`. The official Mandarin item page, official 30-facet key page, Mandarin
reliability page, and scoring-instruction page are each SHA-256-bound in
`packages/personality-assessment/src/ipip-neo-120-zh-CN.ts`. It accepts only explicit local
personality consent, supports pause/resume/cancel/delete semantics, and returns raw keyed
domain/facet sums. It deliberately emits no percentile, high/middle/low label, chart input,
cross-check, clinical field, or user-facing output.

The source audit also fixed a reference-only MIT comparison at commit
`493546d48eb9053aca7e6c55574f4bf8033cc5a4` of
[`b5-johnson-120-ipip-neo-pi-r`](https://github.com/Alheimsins/b5-johnson-120-ipip-neo-pi-r):
all 120 domain, facet, and plus/minus key entries matched the official-bound data. Its English
wording, community translations, and code are not copied or run; it is not a dependency and it
does not constitute a separate scoring implementation, norm, translation validation, or clinical
validation. The exact source archive and relevant file hashes are recorded alongside the item set.

The two rows above retain their historical planning labels for the public product surface. Their
operative implementation state is: psychology-informed narration = `IMPLEMENTED_INTERNAL` and
default off; nonclinical personality = `IMPLEMENTED_UNPUBLISHED` through the separate,
file-only P9 `psychology-self-assessment` Skill. It exposes only explicit-consent IPIP-NEO-120
session handling and de-identified profile output. Local candidate host packaging is now
available solely for release preparation; it is explicitly unpublished and is not evidence of a
real-device install or a host release. P9 does not expose chart/personality cross-checking,
norms, migration, or any clinical instrument. Personality norms, chart/personality
cross-checking, and every clinical instrument retain the stated gates.

## Source-capture record required before implementation

For each instrument, create a machine-readable manifest only after rights permit it:

```json
{
  "instrumentId": "example@1",
  "language": "zh-CN",
  "sourceUrl": "https://official.example/instrument",
  "retrievedAt": "YYYY-MM-DD",
  "sourceSha256": "...",
  "itemSetSha256": "...",
  "scoringVersion": "...",
  "contentRights": "...",
  "translationRights": "...",
  "requiredAttribution": ["..."],
  "validationRefs": ["doi:..."],
  "populationLimits": ["..."],
  "approvedClaims": ["..."],
  "forbiddenClaims": ["..."]
}
```

No Agent may replace an official source with a blog, quiz site, generated translation, copied app,
or undocumented GitHub implementation. Disagreement is recorded per source; it is never
majority-voted away.
