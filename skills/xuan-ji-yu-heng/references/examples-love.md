# 感情解读示例（V1）

以下为虚构、脱敏的单人盘示例，示范怎样回答“对方也喜欢我吗”，不把单人盘当作两人的配对结果。

## 输入事实

- 只有提问者的本命盘，没有对方资料，也没有 synastry 结果或现实互动描述。
- 西方第七宫主星为 Mercury，与 Saturn 存在本命相位记录。
- 当前只提供结构记录及其限制，没有支持互相吸引、对方想法或承诺的规则结论。

### 可交付示例

这份单人盘看不出对方是否喜欢你。第七宫主星与土星的相位，记录的是你本命盘里的关系结构，不是你和对方之间的合盘，不能当作互相吸引或对方愿意承诺的证据。你们目前有联系吗？

### 内部来源（默认不展示）

- chart facts: `western.7thRuler[Mercury]`、`western.aspects`；只引用当前单人盘的记录。
- rules: 本例没有返回相位含义规则，因此不从位置或相位补写性格、承诺、吸引力。
- limitations: 单人盘不是 synastry；对方是否有意愿也不能由盘面替代现实表达。若进一步使用双方资料，先取得双方同意。
