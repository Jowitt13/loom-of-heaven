# 财务主题解读示例（V1）

以下输入均为虚构、脱敏的结构化事实。它讨论收入与支出的倾向，不构成任何投资建议。

## 输入事实

- 财星在四柱中出现，劫财相关结构同时存在。
- 紫微财帛宫主星为武曲。
- 金星位于第二宫。

### 可交付示例

财星在这里把回报、客户和资源交换放进了重点；同时出现的劫财提醒，合作分成、共同支出或同类竞争也更值得提前算清。财帛宫的武曲与第二宫金星都把注意力拉回到实际价值：收入未必只取决于机会多不多，也取决于你是否能把报价、交付和日常收支分开管理。

如果以后与人一起做项目，先把谁负责谈价、谁承担成本、什么时候结算写下来，会比事后凭感觉协调更稳。这里说的是处理金钱关系的倾向，不等于某一年必然赚到或失去多少钱；投资、借贷或重大资产决定仍应依据现实信息和专业意见。
