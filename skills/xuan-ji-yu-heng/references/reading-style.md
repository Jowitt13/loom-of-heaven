# Reading style — the fixed narration template

When the user asks for a reading (吉凶 / 运势 / 事业 / 感情 / 财运 / 学业 / 流年), narrate the
`interpret` output in **this exact order**. It is derived from a worked human reading and is
designed so every host model produces the same, consistent shape. Every number and date must be
traceable to a fact the engine returned — never invent positions, stems, stars, years or odds.

## 术语防火墙（最高优先｜Channel B 第 1-5 部分是无术语区）

Channel B 专题报告的第 1-5 部分与结尾追问是**无命理术语区**。成文后请**删去第 6 部分“专业依据”再检查剩余正文**；只要仍出现下列任一类词（或其变体），就必须重写后才能交付：

- 八字：日主、身强/身弱、得令/得地/得势、格局/建禄/月劫、正财/偏财/财星/财格、正官/七杀/官杀、食神/伤官/食伤、正印/偏印/印星、比肩/劫财/比劫、透干/藏干/通根/贴身/合身、喜用神/用神/忌神/喜用五行、神煞/桃花/咸池/孤辰/寡宿、伏吟/自刑/六合/三合/刑冲合害、日支。
- 紫微：命宫/夫妻宫/官禄宫/财帛宫/疾厄宫/迁移宫/福德宫等宫名、紫微/天府/破军/太阳/太阴等星曜、化禄/化权/化科/化忌、庙旺得利平不陷等亮度。
- 西占：上升/下降/中天/MC、七宫主/宫主星、合相/刑相/冲相/拱相、落宫/失势/落陷、水逆。
- 时间：大运/流年、干支组合（甲戌/戊申…）、偏吉/偏凶/偏中性、窗口期/能量激活/议题浮现。**年份数字可留，“甲戌大运/戊申流年”必须移到第 6 部分。**

这些词**只允许**出现在：第 6 部分“专业依据”、Channel A 完整技术报告、❌ 错误示范、原始 JSON 附件。

**命理 → 现实结果（必须是结果、不是“术语加括号”）：**

- 食神透干/食伤生财 → 擅长把技能、表达或作品变成实际收入；
- 正财贴身/财星有根 → 重视稳定回报、客户关系和现实责任；
- 官杀藏而不透 → 早期承担的责任与拿到的职位/权限可能不完全匹配；
- 官禄宫天府 → 事业更适合稳步积累，靠长期信用和管理能力发展；
- 甲戌大运偏中性 → 当前阶段更适合积累经验、作品和行业位置；
- 喜用五行火/土/金 → 换成具体能力或工作环境（不直接推荐“火土金行业”）；
- 夫妻宫受冲 → 关系可能因城市、工作、距离或未来安排需要调整；
- 劫财 → 同行竞争、合作分账或共同支出增加；
- 财星被冲 → 收入节奏或现金流容易出现波动。

**不要用商业顾问式黑话代替人话。** 强黑话（第 1-5 部分一律不写）：专业壁垒、平台核心、定价权、话语权、决定权、成果外化、高自主度、资源整合、方法论、生态位、赛道、抓手、赋能、闭环、“逐步争取客户、项目和报价上的决定权”。换成具体动作：

- 获得定价权 → 自己报价、知道一项工作该收多少钱；
- 掌握项目决定权 → 可以自己决定接什么工作、怎么做；
- 成为平台核心 → 在公司里成为能独立负责重要工作的人；
- 成果外化 → 把做过的事整理出来，让老板或客户看得见；
- 建立专业壁垒 → 把一项本事练到别人很难替代；
- 逐步走向高自主度 → 以后可以自己挑工作，也可以选择自己接活。

软黑话（职业路径、商业化、可迁移能力、权责与名分、岗位错配、掌握客户/项目）在“30 秒看懂”和前 200 字一律不用；在其余段落也应尽量改成具体动作。若一句话无法用“具体是谁、在什么场景、做了什么”解释，就太抽象，必须重写。可用 `node scripts/loom-chart.mjs lint-reading --input-file draft.md --channel topic`（`--simple` 更严）自检。

## 空话检测（最高优先｜说了等于没说也不行）

第 1-5 部分即使没有术语，也**不得空泛**。凡抽象判断，必须在**同一句**用具体动作或可观察表现讲清楚（可用冒号、括号、“也就是”“比如”等立即解释）。**数字和生活名词只是辅助，不能单独让句子通过；下一句不相关的具体内容也救不了上一句的抽象。**“未来3年稳中求进”“在工作中提高竞争力”必须判错；“把收入、支出、储蓄和合作资金分开记录”通过。常见空话（出现即需在同句补具体动作）：

- 只有抽象目标：提升竞争力、建立长期优势、实现突破、把握机会、稳中求进、持续深耕、做好规划、增强变现能力、扩大影响力、找准方向、完成价值转化、提升关系质量、处理安全感问题；
- 只有抽象能力：专业能力较强、资源整合能力突出、感情中需要边界、财务承载能力较好、事业具有成长空间；
- 建议无法执行：建议主动把握机会、建议加强沟通、建议做好风险控制、建议发挥自身优势、建议保持稳定心态。

反例 → 正例：

- ❌ 逐步争取客户、项目和报价上的决定权。→ ✅ 先在公司参与真实项目、把流程学会；经验多了可以负责更重要的项目、直接和客户沟通，以后自己接活也更清楚该报多少钱。
- ❌ 感情中要处理好安全感与边界。→ ✅ 他不安时可能不直说、而是突然变冷淡或埋头工作；两人约定遇矛盾先把真实想法说出来，不用失联和冷战试探。
- ❌ 财运需要注意现金流。→ ✅ 他有机会提高收入，但家庭支出、合伙分账或买房成本也可能一起增加；即使赚得更多，月底也未必剩得下钱，所以要把日常开支、储蓄和合作资金分开记录。

**不得靠删内容逃避检查：** 报告仍保持 7 步结构与信息密度——不压缩成空洞短句、不删风险/时间线/现实建议、不只写“仅供参考”、不把具体结论都移到“专业依据”、不用同义抽象词替换黑话、不在每句后机械加“例如”而不给真实例子。第 6 部分允许术语，但须与前文结论一致、不得新增前文没有的重大结论。

**不得换词重复：** 同一个判断不能在 30秒看懂、第2、第3、第5 部分换词重复多次；每一节都要提供新信息，高度相似的连续年份要合并（检查器对重复/高相似句给 `重复` warning）。

## 事实边界（最高优先｜不得越界预测）

- **不扩写加薪：** facts 只支持“责任/职位机会”时，不得写成“升职、加薪”；只有输入 facts 明确含收入/薪资变化时才可写加薪。不能把“机会增加”写成“结果一定发生”（改例：“2034到2035年更可能负责重要工作或出现职位调整，但收入是否增加仍取决于公司和岗位”）。
- **不做群体比较与成功保证：** facts 无群体数据时禁用“比同龄人/比大多数人/比别人更强”；性格倾向不得扩写成“肯定能做好/一定做得出来”，须区分“愿意做/可能擅长”与“实际能否完成”（改例：“你可能更愿意耐心拆解并坚持做完；最后能不能做好，还要看经验、时间和团队支持”）。
- **假设场景不当既成事实：** 引擎不知用户现实经历，第3部分场景必须用“例如/可能出现/如果以后/常见表现可能是”等条件表达；不得认定用户已上班/创业/合伙/结婚/异地/买房/负债（改例：“如果以后和别人合伙接项目，实际分到手的钱可能低于总进账”）。
- **参考方向有限度：** 事业正文给“参考方向”最多 3 类、每类最多 3 个普通人熟悉的岗位例子，并注明“只是参考、不代表只能做这些”；完整五行行业映射只放第 6 部分专业依据。

## 固定顺序（7 步）

按此顺序叙述；每步都落在引擎 facts 上，不杜撰、不给百分比或“高概率/机会窗口”这类伪量化。

1. **30 秒看懂.** 开头先给“核心结论块”（见下），让用户一眼知道结论、优势、风险、关键时间与建议。
2. **现实中会怎么表现.** 把命理结构翻成日常可观察的行为/处境（性格、做事方式、关系相处、金钱习惯），大白话、不堆术语。
3. **最可能出现的具体场景.** 给 1-3 个工作/感情/家庭/金钱的具体场景；无真实经历时用“例如/可能表现为/常见场景是”，不得写成用户已经历过。
4. **时间线.** 用用户可见时间表（见“时间表格式”）给年份，**每年同时写有利路径与风险路径**，锚定引擎大运/流年 fact，不编造年份。
5. **可以怎么做.** 针对优势与风险给可执行建议（怎么发挥、怎么规避/经营），反绝对化。
6. **专业依据.** 到这一节才集中列 干支/十神/宫位/星曜/合冲/相位 等术语与 fact 的 `reason`/`evidence`（`ref`/`ruleId`/出处）。**术语只出现在这一节。**
7. **信息可靠性与声明（整篇只一次）.** 出生时间/地点/时区核对——敏感项（随时刻/时辰交界变化）：时柱、紫微宫位、上升(ASC)与中天(MC)；稳健项：大运顺逆与排列不受影响、时间误差仅轻微影响起运日期；近时辰交界（如戌/亥之交）或用真太阳时（如东莞约 −25~30 分钟）可能跨界须核实。然后转述**全部** `warnings` 与流派分歧/不确定性，并给一次免责（传统命理·娱乐与自我反思·**非科学预测**；不构成医疗/法律/投资/人生重大决策建议）。

## 核心结论格式（第 1 步）

每个主题开头给 3-5 条，**只加粗结果句、不整段加粗**；**每条只承担一个结果、原则上一句话**；开头 200 字先答用户最关心的问题、不先解释术语：

> **【核心结论】……**（一句话定性）
> **【最大优势】……**
> **【最大风险】……**
> **【关键时间】……**（锚定引擎年份）
> **【现实建议】……**

## 强制现实化表达

**整篇专题报告**必须覆盖：① 用户能直接理解的结果；② 现实中的行为表现；③ 一个工作/感情/家庭/金钱场景；④ 有利表现与风险表现两面；⑤ 一条可执行建议。**不要求每条核心结论重复覆盖这五项**——核心结论各只承担一个结果、一句话，五项分散到“现实表现/场景/怎么做”等步骤完成。
无真实经历必须用“例如/可能表现为/常见场景是”，**不得写成用户已经历过**。用户主动提供的职业/关系背景可用于挑选更贴近的例子，但**不得用现实经历反向证明命盘**（不写“已验证/证明了 X”）。

## 语言规则（80% 通俗 / 20% 术语）

正文主体用大白话；术语完整保留在“专业依据”。**禁止把下列词当作最终结论**，须翻译成现实结果：
能量激活、议题浮现、喜用发力、三者叠加指向、非线性成长、高密度窗口、财官得地、夫妻宫被加强。
**禁止输出结婚/成功/发财等任何概率或百分比**（命理无可统计验证的概率模型，绝不输出 X%）。
**最终用户可见正文中，即使是否定、引用或反驳，也尽量不直接出现“必须创业、必婚、必分、注定、稳赚、一定发财”等绝对化短语本身**（这些只能出现在“❌ 错误表达”示范里），改用更自然的替代：

- “不是必须创业” → “并不代表只能走创业路线”；
- “不代表必婚” → “不能据此认定当年一定成婚”；
- “不代表必分” → “不能据此认定关系一定结束”；
- “并非注定失败” → “结果仍取决于现实选择与经营”；
- “不是稳赚” → “仍然存在本金和现金流风险”。

翻译对照（示例、非穷举）：

- 官杀发力 → 责任增加、标准变高、可能承担更正式的职位；
- 食伤生财 → 作品或技能开始带来收入；
- 夫妻宫受冲 → 关系可能因城市、工作、距离或未来安排而调整；
- 劫财出现 → 同行竞争、合作分账或共同支出增加；
- 印星旺/透 → 学习、资质、平台、靠山、证书方面得力；
- 财逢冲/劫财夺财 → 破财或现金流波动风险，宜控预算；
- 水逆 → 反复推敲、修改重构（非“思考慢”）；
- 财星（正/偏财）→ 客户、现金流、回报、资源与现实责任（**非“技能”**）；
- 食伤（食神/伤官）→ 技能、作品、表达、产品化与定价；
- 官杀（正官/七杀）→ 职位、规则、管理、考核与责任；
- 冲 → 该领域因城市/工作/距离/家庭/承诺节奏而**调整**（非直接“分手/辞职/破产”）。

## 时间表格式（第 4 步）

用户可见时间表用此表头（干支/十神/合冲/星曜等依据移入“专业依据”）：

| 时间 | 现实主题  | 可能发生什么                     | 怎么应对                                 |
| ---- | --------- | -------------------------------- | ---------------------------------------- |
| 2028 | 感情/居所 | 关系或居住安排可能变动、需要抉择 | 提前沟通城市与未来分工，不必主动制造变化 |

**年份必须同时写有利路径与风险路径**，不得只标“吉/凶/中性”。

## 长度与去重

- 单一追问 500-1000 字；单项专项报告 1200-2200 字；完整综合报告 2500-4000 字（中文字符）。
- 每段不超过 3 句；同一命理事实只解释一次；同一建议不在结论/正文/结尾重复三遍。
- 免责与排盘校对整篇只出现一次；追问入口只保留一行。
- 用户要求“简单说”时可缩短，**不得为凑字数下限强行扩写**。

## 输出质量验收

- 事业报告开头 200 字内，用户须知道：最适合怎样发展、最不适合怎样工作、当前阶段在做什么、最近的重要转折时间。
- 感情报告开头 200 字内，用户须知道：在关系中是什么样的人、最容易出现什么矛盾、适合怎样的沟通方式、哪些年份更需要关注。
- 财运报告开头 200 字内，用户须知道：主要赚钱方式、财务优势、现金流风险、当前阶段、可执行建议。
- **正文即使删除全部八字/紫微/占星术语，仍应能被普通用户完整理解**（术语只在“专业依据”）。

## Rules that keep every model honest

- One judgement per asked topic; do not spray unrelated predictions.
- Trends and years are **model judgement** on top of engine facts — framed as 命理 assessment,
  never as a statistical probability. The engine supplies the sourced 吉凶 facts and the 大运/流年
  timepoints (incl. the per-year 流年 timeline); it does not compute odds. Never output “X%”.
- If a needed fact is missing (e.g. no `polarity` fact for that topic, or time unknown), say the
  reading is limited and stop — do not backfill.
- Keep the tone calm and reflective, not alarmist; frame 凶 as tendencies to manage, not fate.

## 严谨性铁律（避免绝对化与硬伤）

These exist because over-confident readings drift into errors. They are mandatory.

1. **反绝对化 (no fated verdicts).** Never write 天生/注定/必须/一定/只能/不能-style life
   destiny (“天生不能打工”“必须创业”“注定 X”). A birth chart shows tendencies and probabilities,
   not a single fate. Give **multiple viable paths + conditions**. Preferred shape for e.g. career:
   “先借平台建立专业壁垒 → 逐步掌握客户/项目/定价权 → 走向高自主度；既可创业，也可成为公司核心/项目
   负责人/合伙人。”
2. **只用引擎给的事实与其 `reason`；禁止杜撰机制。** Do not invent a 命理 causal chain that the
   engine did not output (e.g. “七杀在夫妻宫→为伴侣拼事业”). If you cite a mechanism it must be a
   returned fact’s `reason`/`evidence`. When several facts point one way, say “多项指向……”, hedged.
3. **系统隔离，术语不串。** Keep each system’s vocabulary inside that system: 紫微 star names
   (天相/破军…) are **not** BaZi 十神 (天相 ≠ 印星). Do not translate one system’s term into another.
4. **亮度/尊贵如实，不得升级。** In Zi Wei, brightness like 庙/旺/得/利/平/不/陷 must be relayed as
   given — “不” or “平” is **not** “陷”. In Western astrology distinguish **失势/detriment**
   (e.g. Venus in Aries) from **落陷/fall** (Venus falls in Virgo); never call detriment “落陷”.
   A ruler in the 4th house is multivalent (家庭根基 **and** 建筑/地产/空间/居住/在家或固定基地办公/
   个人工作室/家族业务/事业与地域及家庭根基关系深), not merely “依赖家庭资源”.
5. **一致性自检。** Do not contradict yourself (e.g. “MC 天秤重客户协作” then “不适合社交工作”).
   Reconcile or drop one.
6. **宫位按本义，不挪用。** Read each palace by its own meaning: 疾厄宫 is health / stress / injury
   risk (紫破擎羊 → 防过劳/伤病), **never** “身体是事业资产”而鼓励硬扛.
7. **时机措辞要留余地。** No “必是高峰/稳赚/必然”; say “机会较强，同时留意波动/资金压力/责任加重”.
   Distinguish “已透 vs 再加强” (don’t say a star “首次出现” when the natal chart already has it).
   Anchor 应期 to the engine’s 大运/流年 冲合 facts (e.g. 流年冲日支之年), not to invented dates.
8. **占星与八字互参，不互相覆盖。** When systems agree, say so; when they diverge, present both and
   note the divergence rather than forcing one to win.
9. **十神象义对照（勿张冠李戴）.** 财 = 回报/客户/资源/现金流/现实责任；食伤 = 技能/作品/表达/
   产品化/创造；官杀 = 权责/管理/规范/竞争；印 = 学习/资质/平台/靠山/证书；比劫 = 同侪/竞争/合作
   分账。**财 ≠ 专业技能**（技能与产品化看金/食伤）。
10. **财格语义.** 财格 ≠ “只靠成果、不在乎职位”。更准确：需要职位带来**真实权责、专业控制力、
    合理回报**；只有头衔、没有实权的岗位难以长期满足。
11. **官杀藏/不透 ≠ 排斥组织.** 官杀藏而不透只说明早期权责/名位不直接显现，**不得**推出“不适合
    大厂/体制”。改写：“不宜只靠年资与人情爬升，但适合在大平台担任技术、项目或专业核心；宜提前
    准备选择权，而非为应验而主动辞职。” **明令禁止**“不适合大厂/体制”“必须主动求变”这类绝对化表述。
12. **紫微忌单星定论.** 单颗星/单宫不下断语，须结合三方四正、四化、对宫与财帛/迁移综合。例：巨门
    化权 = 分析/辩论/咨询/专业话语权，但需补“表达锐利、质疑过多、措辞易引争议”；太阳亮度“不”
    ≠“陷”，不得推“大平台没有光环”；地劫不单判“名声起落/项目停滞”。紫微宜总结为“职业道路可能
    非线性，靠专业判断、表达与解决复杂问题建立影响力；不依赖头衔，但不排斥大平台”。
13. **占星 水逆 ≠ 思考慢.** “慢工出细活”多来自水星金牛；水星逆行更偏**反复推敲、内在思考、修改
    重构**，不要直接写成“思考慢”。
14. **流年整年 ≠ 单一定性.** 某元素旺的年份（如金旺年）“通常利作品输出”，但仍须结合当年天干、
    合冲与官杀强弱，不可一概说“最佳时机”。

15. **五合合而不化.** 天干五合以引擎措辞为准（“合，化X之象；合而不化” / “化神当令、有化气之机”）；不得把“合”写成已“合化X”。正财/官星两透只说“贴身合 vs 遥见”，**不按财/官星数量推伴侣数量**；配偶星明显只表伴侣议题与机会不弱，≠“婚姻质量一定好”。
16. **夹宫术语严谨.** “夹”＝两星分列目标宫**左右相邻两宫**；星在夫妻宫、另一星在福德宫**不叫**“夹夫妻宫”，据实写“夫妻宫见X、福德宫见Y”。
17. **疾厄宫只论健康（强化#6）.** 紫破擎羊等在疾厄宫只作健康/压力/伤病/激进倾向，**禁**推“性驱力强”；亲密与性综合 夫妻/福德/子女宫 + 桃花星 + 西方金星/火星/冥王，且只谈模式、不定强弱。
18. **夫妻宫主伴侣与关系（非本人）.** 夫妻宫星曜（如太阴化科）先描述**伴侣特质与关系氛围**（易被温和细腻/重体面者吸引、关系外显克制），非本人性格；仅当身宫落夫妻宫可加“本人把自我价值投入关系”，仍不得断“深情不表达”。
19. **迁移宫为倾向、非证明.** 天机/禄存在迁移宫主变动/流动/远距离**倾向**，**禁**断“异地不是障碍”；地空提示信息差/计划落空。**禁用用户口述的现实经历反证或“验证”盘面**（不写“已验证/证明了X”）。
20. **孤辰/寡宿为辅星.** 至多表示压力下退回个人空间、宁缺毋滥、慢热，**禁**“孤寡底色/孤独终老/婚姻不顺”。
21. **大限宫语义 + 虚岁.** 大限按**虚岁**且注明；父母宫大限主学业/家庭/身份/长辈影响，**≠恋爱幼稚/冲动**；进入夫妻大限主伴侣议题上升，**≠必然结婚**。
22. **金星星座＝初期表达风格.** 金星白羊＝表达直接、需主动感与自主空间，**不得**推“激情快来快去”；月土合七宫（承诺慎重、怕失控/被拒、以责任表达爱但对方未必收到）权重更高，与太阳/水星金牛的稳定性并观；七宫主逆行/受克＝易“我以为说清了”实则沟通不足、以行动代替明说。
23. **婚期年份纪律.** 男配偶星＝财、女＝官；**正官(男)/正财(女)年、纯桃花年非核心婚期**（桃花＝异性缘/机会弱信号）；逢冲/自刑/伏吟/相害之年标“变动·反复·需调整”而非“吉”；不遗漏引擎标出的“配偶星临”之年。判断**具体某段关系**须走 `synastry`（双人合婚），单人婚姻版只作个人倾向。

## 常见追问 playbook（每类一套固定模板，均锚定引擎事实）

回答高频追问时，按下表取用引擎事实 + 上述固定 7 步顺序（30秒看懂→现实表现→场景→时间线→怎么做→专业依据→声明）与现实化/语言规则，一律反绝对化。

- **什么时候结婚 / 正缘何时来：** 用 `婚姻/正缘应期` fact 的**分级标签**（推进机会 vs 变动/反复 vs 桃花弱信号）。逢冲/自刑/伏吟/相害之年为“变动·需调整”非“吉”；桃花年≠婚期；只给“有利窗口年份”、不给“几岁必婚”；时间未知则声明受限。
- **对象长什么样/特质：** 用 `配偶画像` fact（配偶星五行+紫微夫妻宫+下降/金星/**七宫主星**）与“西方关系相位/第七宫主星”fact。只给“倾向性特质”，明确“参考、非精确断人、勿对号入座”；夫妻宫读**伴侣/关系**而非本人性格。
- **适合什么行业：** 用 `适合行业方向` fact（喜用五行→行业大类）+ 十神象义（食伤=专业输出、官杀=体制管理）。为参考方向，非唯一。
- **最近/今年适合投资吗：** 用当年逐年流年 fact 的财/食伤与 polarity + 是否逢财星被冲/劫财。**必强调风险与“非投资建议”**；不说“稳赚/必赚”。
- **今年需要注意什么：** 用当年流年 fact 的冲/害/刑/忌神/羊刃，及该年十神主题（官杀=压力/规则、食伤=表达/口舌）。给“留意点+应对”，不吓人。
- **桃花/感情机会年、事业突破/转运、财运高峰/破财风险：** 均从逐年流年的十神+合冲读取（桃花/配偶星=感情；官杀/食伤生财=事业；财旺=财运；劫财夺财/财逢冲=破财风险），皆为趋势非定数。
- **适合合作还是单干：** 看比劫（合作/合伙，但防分账）与财/官（自主掌控）强弱；给利弊，不绝对。

## 合婚/关系分析叙述模板（多人）

从 `synastry` 的 `findings` 叙述，顺序固定（保留下列结构；上述语言/现实化/免责一次规则同样适用）：

1. **先结论（契合度 + 关键张力）：** 用 `overall` 汇总 + 各系 polarity 分布，给“总体相吸/需磨合”的定性，不给百分比。
2. **依据（引用事实）：** 八字（生肖/日支夫妻宫/五行喜用互补/配偶星契合）、紫微（命宫↔夫妻宫互涉）、占星（日月/金火互相位），每条引其 reason。
3. **按关系类型取角度：** 夫妻=长期相处/责任/矛盾点；情侣=能否走向婚姻；暗昧=能否成、主动方；前任=复合可能与分手主因；家人/朋友/合作=相处与协作。
4. **相处/推进建议 + 免责：** 张力点给“如何磨合”而非“不合”；**严禁**“注定在一起/必分手/命中注定”；契合与否是相处经营的结果，非命定。
5. **多人时：** 先确认要分析哪两人及其关系（未说先问）；逐对分析，不把多人混为一谈。
