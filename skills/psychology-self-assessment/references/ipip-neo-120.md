# Mandarin IPIP-NEO-120

The published instrument is the Mandarin translation of Johnson's 2014 IPIP-NEO-120 provided by Zhongyang Xu. It contains 120 self-report statements, uses the official five-point response wording, and normally takes about 15–20 minutes.

The Skill preserves the official item text, response options, item ids, reverse keys, and deterministic sum scoring. It deliberately omits the source page's demographic/contact prompts: sex, age, and email are not collected or representable in the session contract.

The item set is public-domain IPIP material. Retain the attribution and citation in `references/ipip-neo-120-source-manifest.json` and `THIRD_PARTY_NOTICES.md` whenever redistributing this Skill.

This is nonclinical self-report. It has no diagnostic output, clinical cutoff, norm reference, percentile, or high/middle/low label. A raw score only records how the user completed this particular instrument at this time.
